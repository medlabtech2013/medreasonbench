## 🧠 Overview

MedReasonBench is a custom AI evaluation framework designed to go beyond traditional accuracy metrics.

It evaluates:
- Reasoning
- Uncertainty handling
- Decision-making

using clinical-style scenarios and structured lab data.

---

## 🔬 Features

- Clinical-style test cases  
- Custom scoring system  
- Confidence penalty logic  
- HL7-style data simulation  
- Interactive Streamlit dashboard
